# 代码审查与交互细节修复（2026-10-25）

本轮检查了增量投影、请求表单、窗口拖动与隐藏、键盘焦点、复制反馈和生产 CSS。沿用当前布局与玻璃风格；改动仅在源码及本地构建，未替换安装版插件。

## 已修复的问题

| 问题 | 复现与影响 | 修复 |
| --- | --- | --- |
| 问题 ID 与对象继承属性重名 | 合法 ID `constructor`、`toString`、`__proto__` 被当作已有草稿，触发 `.filter` / `.trim` 报错，答题视图无法正常渲染 | 只读取草稿对象自身的字段；单测覆盖三种 ID，真实 Electron 覆盖 `constructor` |
| 新增 `__proto__` 会话丢失 | Main 已接受会话，但 preload 增量赋值调用了对象原型 setter，没有生成自己的会话项 | 使用显式数据属性保存会话；覆盖新增、更新、删除，以及 Host → Main → preload → UI 的实际选择流程 |
| 问题队列切换丢草稿 | 输入第一份答案，切到问题 2 再回来，原文字清空 | 将草稿和提交阶段按完整请求身份保存在 QuestionCard 中；仅挂载当前表单，结束请求立即清理，忽略迟到回调 |
| 隐藏窗口残留抓取状态 | 胶囊按下后隐藏，`data-drag=pressed` 仍然存在；透明窗口的页面可见性事件不能可靠兜底 | 用 Main 发布的原生 `WindowState.visible` 清理手势与动效，并在卸载时释放订阅 |
| CSS 压缩改变缩放动效语义 | 生产 CSS 将 `transform:none; scale:1.16` 合并为 `transform:scale(1.16)`，而过渡和后续覆盖仍作用于独立 `scale`；原生验收读到 `scale:none` | 关闭 CSS 压缩，保留 JS 压缩和原样式。使用原阈值复测：`scale=1.16`、明显倾斜、有限回弹、玻璃滤镜层无 transform 均通过 |

最后一项是审查发现的此前生产压缩回归。没有降低拖动验收的缩放阈值；脚本新增失败数值记录，以便下次直接定位计算样式。

## 交互与 UI

- “过程 / 步骤”支持左右方向键循环、Home / End，焦点、选中状态和关联面板同步；只有活动标签占用 Tab 停靠点。
- 过程列表与 Todo 列表可直接获得键盘焦点；输入框、选项和列表补充可见焦点边框。
- 复制预览后显示短暂的“已复制”或“复制失败”，随后恢复按钮文案；反馈按请求身份隔离。
- 保留原生位置移动、局部鲸鱼与内容反馈，不对整个玻璃滤镜层做变换；保留减少/关闭动画以及系统减少动态效果。
- 问题草稿只在当前请求面板的内存里保留，不写文件；请求结束、切换会话/连接或离开面板后不重放旧草稿。切换队列本身不会发送答案。

## 构建体积与边界

本轮桌面输出约 **627 kB**；CSS 约 **111.75 kB**，比压缩版本增加约 18 kB，JS 继续压缩。相比最初约 1.42 MB 的输出仍明显更小，但本轮优先修正动态样式语义，不把 CSS 字节数当作唯一目标。

真实用户 Desktop 模型任务、审批/问答闭环，以及跨显示器 DPI 和主观手感没有在本轮补验。本轮没有修改 DSH 安装、Profile 或安装版缓存；用户安装版仍需更新后才会包含这些修复。
