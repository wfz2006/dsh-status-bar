# 胶囊拖动动效 · 本地实验

范围：仅调整拖动手感与胶囊反馈，不改数据接入、审批或插件启动链路。保留当前仓库的其他升级，未经用户体验确认不提交、不推送 GitHub。

## 行为

- 按下：内容轻压，鲸鱼回应抓取。
- 拖动：原生窗口按鼠标位移直接移动；鲸鱼随方向倾斜，内容最多滞后 4.8 DIP，高光随速度偏移。
- 快速松手：速度驱动的阻尼回弹，最大偏移小于 14 DIP，560ms 后精确回到落点；没有自由滑行。
- 停稳再松手：不触发位置回弹。回弹中重新抓取立即中断，继续从当前窗口位置拖动。
- 减少动画、关闭动画与系统减少动态效果偏好均保留直接拖动，关闭新增动效。
- 展开、切换面板、隐藏、失焦、取消指针和卸载时清理动效；不同指针不能接管当前手势。

窗口通过现有原生定位助手移动，仍然只改位置。整个玻璃滤镜层没有缩放、旋转或拖动变换，RGB 折射保留；新反馈只作用于内容与独立反光层。没有增加动画依赖；每帧数值留在命令式控制器和 CSS 变量中，不触发 React 状态更新；静止时没有持续运行的动画循环。松手原生移动提交上限约 60Hz，忙碌时只保留最新目标。

## 参考

- [Apple · Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)：连续直接操作、保留抓取点、可打断反馈。
- [Motion · React drag](https://motion.dev/docs/react-drag)：根据释放速度决定惯性，使用阻尼弹簧收束。此项目采用局部有界回弹，没有照搬整块缩放或自由抛掷。

## 本地运行与验收

```powershell
pnpm build
node scripts/drag-motion-preview.mjs
```

预览使用临时独立配置与 Mock 数据，默认不启用屏幕取样；退出可通过胶囊右键菜单。现有“设置 → 动画”中的完整/减少/关闭可作手感对照。不会更新已安装插件或 DSH Profile。

```powershell
pnpm lint
pnpm typecheck
pnpm test
node scripts/drag-motion-acceptance.mjs
node scripts/motion-acceptance.mjs
node scripts/experience-acceptance.mjs
```

新原生验收采用 Playwright 鼠标驱动实际 Electron 窗口，采集原生 bounds：直接跟手、尺寸固定、短回弹、精确落点、再次抓取、停稳释放、点击/键盘与减少动画。另启用一次局部取样检查多位置更新，随即关闭；报告只保存几何与计数，不保存屏幕像素。纯函数/控制器测试覆盖 60/120Hz、掉帧、指针身份、慢速传输合并、取消和停止后无新帧。

验收产物保存在被 Git 忽略的 `reports/drag-motion/`。这些检查不能代替用户对实际手感的最终确认。旧 `drag-optics-acceptance.mjs` 本轮在速览背景像素差异断言处未通过：窗口移动与尺寸检查先通过，但所选屏幕像素没有达到差异阈值；未据此声称完整光学视觉验收通过，也没有放宽该断言。

手动体验重点：慢拖、快速换向、斜向拖、松手时停顿、回弹中再次抓取、屏幕边缘、多显示器跨屏，以及完整/减少动画切换。跨显示器 DPI 与主观手感仍需用户确认。

## 2026-10-23 本轮结果

用户体验第一版后反馈“动效不是很明显”。第二版将速度反馈灵敏度提高到原先约三倍，鲸鱼倾斜上限约 14°、抓取放大到 1.16 倍，并强化方向高光。释放回弹增加到最大 14 DIP / 560ms。原生窗口仍在按住时直接跟手，整个玻璃滤镜层没有变换。

- 第一版：lint、typecheck、build、22 个测试文件共 200 项测试通过。
- 第一版：新原生拖动验收、既有 motion/experience 验收通过。实测胶囊保持 290×44 DIP，按住移动 120 DIP；释放轨迹为 x=370→375→370。局部取样收到 10 帧、覆盖 9 个不同位置，随后已关闭。第二版结果另记录于下方。
- 保留 RGB 滤镜 URL，玻璃表面 transform 为 none。`native-rest.png` 为所属窗口的原生截图；它验证静止外观，不作为动态帧率或全部光学效果验收的依据。
- 所有源码改动只在本地工作区；已安装插件、DSH Profile 与远程仓库未修改。

第二版验证：lint、typecheck、build 与原生拖动验收通过，控制器测试增加到 10 项。普通速度的原生轨迹中，鲸鱼倾斜约 9.3°、放大 1.16 倍；释放位置 x=370→380→369→370，最终仍回到落点。玻璃表面 transform 继续为 none，RGB 滤镜 URL 保留；取样轨迹覆盖 10 个不同位置。上述是自动化轨迹数据，主观可见程度仍由用户体验确认。
