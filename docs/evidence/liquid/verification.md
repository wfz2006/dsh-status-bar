# 液态玻璃视觉修订验收

日期：2026-10-17，Windows 11 Build 26300，本机显示缩放下验收。

- 原因：旧版本窗口背景和页面底色近不透明；默认 `WS_THICKFRAME` 与 CSS 全圈浅色描边叠加。旧布局使用 420×560、58px 标题栏、多处重复说明和默认展开的审批详情。
- 修订：透明窗口 + 默认原生 Acrylic；关闭 thickFrame/shadow，以原生圆角 region 裁切绘制区域；保留短局部光学高光，去掉整圈白色 CSS border。独立实色降级可切换。
- 紧凑：默认约 340×300 DIP，标题栏38px，当前会话/状态/步骤/Todo 为主；审批和活动设置按需展开，默认内容没有滚动条。
- 动画：420ms 改变实际原生窗口 bounds，宽度先舒展、内容渐入；记录了多个中间窗口尺寸。减少动画即刻切换，快速反向点击不会保存中途尺寸。
- 缩放：去掉系统 frame 后补应用边缘/角落拖拉区域；右下角真实指针拖拉自动化通过。
- 旧几何迁移：仅首次读取无版本偏好时收紧旧预览大尺寸；新版本用户主动改的尺寸保留。

`pnpm lint`、`pnpm typecheck`、`pnpm test`（21 项）、`pnpm build` 与 Electron 桌面回归通过。形变、减少动画、紧凑无滚动、反向切换和原生缩放证据见 `acceptance.json`。桌面回归证据见上级 `desktop-smoke.json`。

`native-acrylic.png`、`native-clear.png` 是 Windows 系统合成截图，背景是测试创建的绿色/金色/蓝色窗口，不是壁纸素材假贴图。检查确认背景颜色能透过、Acrylic 比清透模式模糊、圆角外无旧白色矩形框。截图与页面截图不同，能看到 DWM 背板。
