# 鲸鱼水池独立形态 · 本地开发验证

新增「鲸鱼水池」，与原版胶囊、速览、详情、待处理请求并列出现在菜单里；设置中的「外观形态」也可切换。保留清流、轻舟、水笺三种排版与三种水池轮廓。原版为默认外观，旧设置不会被自动切换。

首次安装或首次更新到包含本功能的版本时，若本地偏好尚未记录 `whale-pool-v1`，显示介绍。选择立即体验、暂时保留或用 Esc 关闭后记录已处理；后续启动不再提醒。介绍也可从设置中主动重看。记录独立于外观设置，调整其他设置不会清掉它。

水池使用现有会话投影，不带原型的演示场景选择器与假任务。折叠时仅显示鲸鱼、菜单和必要的待确认角标；点击展开。完整详情、会话切换和审批复用原有视图与身份校验；没有新增自动批准。断线不冒充任务完成。

## 本地启动

双击本开发副本中的 `启动鲸鱼水池预览.cmd`。使用 `reports/whale-pool-preview` 独立配置，不读取或覆盖已安装版本的配置。首次启动可看到介绍；数据源默认未连接，可在设置中通过既有入口连接。

本轮修改在 `D:/codexwork/dsh/worktrees/whale-pool`、分支 `codex/whale-pool-form`；没有合并、发布、安装或修改用户 DSH Profile。

## 验证

- `pnpm exec vitest run`：24 个测试文件、221 项完整单测通过，包含设置兼容、介绍只提示一次、旧菜单独立选择、自动审批材质恢复、池形态尺寸保护。
- `pnpm exec tsc --noEmit`、`pnpm exec eslint .`、`pnpm build`。
- `node scripts/whale-pool-acceptance.mjs`：8 组专项检查通过，独立配置目录的新装、升级、两种选择、重启、三种排版、断线空状态、待确认角标、GPU 上下文丢失与恢复、原版视图和审批只读保护。结果：`reports/whale-pool/result.json`，页面错误为 0。
- `node scripts/desktop-smoke.mjs`：原版完整桌面回归。初期置顶断言出现两次失败；独立诊断和随后未修改脚本重跑均通过，未通过修改断言掩盖。保留该环境时序记录，不据此承诺所有桌面环境都已验收。

GPU 资源在卸载时释放；隐藏时暂停动画；水池显示时暂停原版桌面取样，回到原版或设置面板时恢复原取样偏好。减少动态效果和关闭动画会直接显示稳定状态。

独立审查确认并修复了自动进入审批时材质未恢复、轻微调整尺寸误切视图两处问题。

尚未完成：真实 Desktop 模型会话和授权闭环、物理多屏/DPI 切换、长期 GPU/内存性能预算、发布安装流程。本开发版不宣称这些已通过。
