# 信息层级与操作体验升级 — 2026-10-18

## 本轮改动

- 胶囊保留标题、鲸鱼、待处理数与 Todo 任务进度；轮数/Agent 执行次数进入悬停说明与展开视图，避免两种“步数”混淆。
- `taskUsage` 保留原始统计但按任务状态呈现：运行速率使用当前值，非运行态标注“上次”，断线不呈现速率并标明“离线快照”。无 token 总量时不补零。
- 详情用量明确分两行：工作概况、累计用量。只有当前运行速率使用强调色，其余数值使用清晰中性色。
- 会话入口显示当前名称和总数，列表包含状态与选中标记。方向键打开/移动，Home/End 定位，Enter 选择，Esc 取消并恢复焦点，Tab 离开并关闭。修复快速 Home→Enter 被延迟焦点覆盖的问题。
- 默认审批窗口高度 340→300 DIP；底部决策栏继续固定，长内容在正文滚动；只读请求增加锁形“只读预览”标识，真实提交与权限逻辑不变。
- 减少持续流光与状态光圈，降低文字波动幅度和频率；小鲸鱼保留主要动态。动画关闭、减少动画和系统偏好继续生效。
