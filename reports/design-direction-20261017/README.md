# 成熟产品参考与建议设计方向

调研日期：2026-10-17。范围：DSH Glass 现有悬浮面板的整体视觉、材质与配色；以下为当时提出的调研方向。用户随后确认实施，运行版本及样张见 `../refined-ui/`，视觉评价仍待用户验收。

## 推荐参考

1. [Raycast Notes](https://www.raycast.com/core-features/notes)：与本项目同属轻量悬浮工作窗口。参考其内容优先、较少的常驻操作、列表密度和键盘交互。官方提供任务列表与悬浮便签样图。
2. [Linear 2026 interface refresh](https://linear.app/now/behind-the-latest-design-refresh)，2026-03-12：参考控件一致性、较少的彩色图标底、弱化分隔线、紧凑标题栏。其设计记录强调让与当前任务相关的内容优先，而非让所有元素具备相同视觉重量。
3. [A Linear spin on Liquid Glass](https://linear.app/now/linear-liquid-glass)，2025-10-21：参考透明度、深度和高光如何服从专业工具的清晰度与专注。该文明确其移动端实现没有复刻折射，因此不能当成本项目真实折射的实现或验证依据。借鉴其层次与克制，不照搬其模糊底。
4. [Craft Liquid Glass update](https://www.craft.do/blog/craft-update-3-2-6)，2025-09-15：参考内容中心、柔和圆角，以及仅在有助于清晰度与专注的位置使用玻璃。文章里的旧促销不属于当前推荐内容。
5. [Apple HIG · Color](https://developer.apple.com/design/human-interface-guidelines/color)：材料从后方内容获取色彩，人工色彩主要用于值得强调的状态与主操作。作为色彩约束，不将平台API能力当成Windows能力。

## 对当前界面的判断

以下为基于现有界面和源码的设计判断，不是上述产品的官方评价：

- 当前蓝、紫、绿、红、琥珀同时在文字和色面中出现，任务、命令、计数和操作之间的主次减弱。
- 许多局部区域都带亮边，容易产生框中框、逐项描边的感觉。仅改变透明度无法统一这种视觉重量。
- 控件虽已使用SVG与内缩布局，标题、辅助信息、操作、代码区域仍需要同一套尺寸、对齐和色彩规则。

## 推荐组合：Raycast布局 + Linear层级 + 清透玻璃

- 材质：保留用户已选的清晰透光与实际折射；高光集中在外缘和交互处。保持现有边缘厚度的意图，但调整光照分布；内部依靠对齐、间距和轻微明度差区分层次。
- 配色：默认无色透明表面、实黑/亮白文字、一个蓝色强调。琥珀只在待确认时出现，红绿只用于错误、允许/拒绝、完成。命令文字回到统一正文/代码墨色，工具名称使用小型中性标签。
- 文字：通过字号与字重建立标题、当前动作、辅助信息三级；文字保持实色，不以透明文字营造轻盈。
- 操作：一个明确的主操作，其余控件更安静；折叠状态仅呈现最必要信息。焦点、禁用原因、菜单可达性和键盘行为保留。
- 工程：视觉落地前以当前任务、审批、设置三种真实内容做对照。清晰玻璃遇到复杂壁纸仍需实机可读性验收。

候选强调色：蓝 #5271E8、琥珀 #AD7A21、绿 #237A61、红 #A94358。这些是拟议色值，并非产品官方token；亮/暗背景对比度须在实际落地时分别验证。

当前建议优先验证一套统一视觉语言，再逐个打磨控件；避免继续以每个组件单独增加颜色或边框的方式推进。
