# 拖动命中与移动实时背景修复

2026-10-17。用户反馈大部分文字不能拖动、拖动时保持旧位置背景。

根因：速览/详情没有内容拖动行为，只有10px原生拖动条；文字可被选择。原生移动路径还可能阻塞Main定时任务；此前helper与Main要求取样前后位置完全不变，移动中的帧被连续丢弃，但旧画布没有按屏幕位置更新。

修复：统一主表面的指针拖动，标题/任务文字/空白/胶囊/速览均可拖；6px阈值区分点击，单个移动IPC在途合并位置。真实按钮、输入、选择框、label、summary、命令pre和resize区域保留交互。取消文字选择只应用于拖动表面，命令仍可选中复制。移除原生拖动条的modal移动路径。

背景取样仍限原授权区域。捕获后的像素只在完整覆盖当前窗口时按世界坐标重投影；多余边距裁剪到当前窗每侧最多48物理px。移动/缩放即时通知画布调整采样原点，无覆盖时隐藏旧纹理，等待新帧，不把旧位置画面固定贴在新位置。原生身份、可见性、排除自身、长度与停止校验保留。

新增 `scripts/drag-optics-acceptance.mjs` 先在旧实现复现失败：`peek text must drag the window`。修复后，实际Electron指针保持按下，拖动标题/Todo/胶囊36 DIP分别收到18–20帧、各12个不同位置，实际黑白像素发生变化；较快拖动120 DIP期间收到12帧、12个不同位置。没有选中文字或误展开；普通点击、键盘Enter、返回、设置select和命令文本选择通过。详情见 `acceptance.json`。

33项单测（包括重投影裁剪/不覆盖拒绝）与lint/typecheck/build通过；原有光学输入/停用/隐藏/实色/异常停止及桌面交互另行回归。不据这些样本承诺所有DPI/机器的显示帧率。真实DSH接入仍BLOCKED。

后续补测：先前此脚本未断言尺寸，遗漏了150% DPI的增长问题。本轮使用SWP_NOSIZE移动；当前脚本在每个按住鼠标的移动步骤检查页面viewport不变，再检查实际输入随位置变化。四形态连续320次移动的原生尺寸检查见 `../move-size/`。最新单测34项。
