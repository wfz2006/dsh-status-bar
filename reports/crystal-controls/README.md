# 彩色控件的透明玻璃修订

本记录保留前两轮控件材料修订的设计背景。后续统一视觉已落地，见`../refined-ui/`；新主题下再次通过真实条纹/实色对照，最新量化数据以`pixel-analysis.json`为准。

2026-10-17，用户要求把几块实色区域改为晶莹剔透的感觉。

最新修正：用户指出首轮仍灰蒙，移除内部控件5px模糊、顶部操作组8px模糊、灰白/暗色默认衬底与外阴影。大面积斜向白高光改为顶部3px内的边缘反光，功能色仅保留6–10%的薄染色；背景清晰透过，文字仍为实色。显式易读档保留较薄的局部阅读衬底。整面玻璃、窗口几何、审批机制与已授权取样范围未变，没有另加取样或假壁纸。

`scripts/crystal-controls-acceptance.mjs` 使用真实原生条纹背景，导图前逐像素检查限定区域输入只来自自有双色背景，亮暗各拍清透与临时实色对照，并断言backdrop-filter为none。`scripts/analyze-crystal-controls.py` 在避开文字/边框/圆角的内部扫描行测量背景条纹起伏：亮背景30.83/30.20，暗背景14.41/14.52，实色对照均0；相邻像素最大差分别60–62和28–29，确认条纹边缘清晰。首轮磨砂版对应起伏仅12.80/12.74及6.47/6.27，旧结果与样张保留在`frosted-before/`。见当前`pixel-analysis.json`。
